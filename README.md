# QuantSight ML Teachable Lab - Simple UI

Double-click `ML_LAB.bat`.

The browser opens one local page at:
http://127.0.0.1:8765

Buttons:
- Collect Historical
- Validate Data
- Build Features
- Train Models
- Promote Model
- Export for QuantSight

Status:
- Massive API connected/missing
- validation status
- approved model
- current running task
- BTC/ETH/SOL row counts for 5m/15m/1h/funding/orderbook
- latest command result

Only API key needed for this lab:
MASSIVE_API_KEY

Bybit credentials are not required because this lab uses public Bybit market data.
